# 🏛️ WinterTavern 社区创意工坊 (Community Workshop)

欢迎来到 **WinterTavern 社区资源与创意工坊** 官方仓库！

本项目是 WinterTavern (冬日酒馆) 客户端的官方云端资源生态中心，专为广大角色扮演爱好者、Galgame 玩家与 TRPG 跑团爱好者提供高质量的免费资源分发。

---

## 🌟 四大资源分区 (Workshop Sections)

| 分区 | 目录 | 说明 | 支持格式 |
| :--- | :--- | :--- | :--- |
| 🧩 **MOD 插件工坊** | [`/mods`](./mods) | 扩展客户端原生功能的独立 MOD 插件（好感度状态机、Token HUD、正则美化等） | `.json` / `.zip` |
| 🎭 **角色卡工坊** | [`/characters`](./characters) | 精美二次元、魔幻、赛博朋克等各色高水准角色卡 | Tavern V2 JSON / PNG 卡 |
| 📚 **世界书工坊** | [`/lorebooks`](./lorebooks) | 宏大世界观设定、法术阶位法则、派系背景知识库 | World Info JSON |
| ⚙️ **叙事预设工坊** | [`/presets`](./presets) | 恋爱心流、硬核跑团、沉浸描写等高级系统提示词预设 | Preset JSON |

## 🚀 国内直连高速镜像通道 (Mirrors)

为了保障国内用户免翻墙极速访问，本项目全面接入免费公共 CDN 与 GitHub 镜像：

* **全球直连**：`https://raw.githubusercontent.com/piaoranjieli/winter-tavern-workshop/main/`
* **jsDelivr CDN**：`https://cdn.jsdelivr.net/gh/piaoranjieli/winter-tavern-workshop@main/`
* **国内加速镜像**：`https://ghproxy.net/https://raw.githubusercontent.com/piaoranjieli/winter-tavern-workshop/main/`

客户端内部已内置智能镜像调度，自动挑选当前延迟最低的通道进行下载。

## 🤝 社区贡献指南 (Contributing)

我们热烈欢迎社区创作者分享你的原创角色卡、世界书、Prompt 预设或新 MOD！

1. Fork 本仓库。
2. 将你的作品放入对应的目录（例如新角色放入 `characters/cards/`，并在 `characters/index.json` 中追加信息）。
3. 提交 Pull Request，通过测试后将自动同步到全球玩家的客户端工坊大厅中！
